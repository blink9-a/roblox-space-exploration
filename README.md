# roblox-space-exploration

## 프로젝트 소개 (Project Overview)

**Space Mining Explorations**는 Roblox Studio로 제작하는 우주 탐험 및 채굴 게임입니다.
(**Space Mining Explorations** is a space exploration and mining game created with Roblox Studio.)

플레이어가 여러 지역과 행성을 탐험하며 광물을 채굴하고 자원을 수집하여 성장하는 게임을 목표로 제작하고 있습니다.
(The game is designed for players to explore different areas and planets, mine minerals, collect resources, and progress.)

## 주요 특징 (Main Features)

* 우주 및 행성 탐험 (Space & Planet Exploration)
* 광산 탐험과 광물 채굴 (Mine Exploration & Mining)
* 자원 및 아이템 수집 (Resource & Item Collection)
* 다양한 건물과 탐험 지역 (Buildings & Exploration Areas)
* 성장에 따른 새로운 행성 탐험 (Planet Progression)

## 실행 방법 (How to Run)

1. `game` 폴더의 `.rbxl` 파일을 다운로드합니다.
   (Download the `.rbxl` file from the `game` folder.)

2. Roblox Studio에서 파일을 엽니다.
   (Open the file in Roblox Studio.)

3. `Play` 버튼을 눌러 실행합니다.
   (Click the `Play` button to run the game.)
